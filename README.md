**Ultra Contrast** — лёгкая портативная утилита для Windows, позволяющая в реальном времени тонко настраивать контрастность, глубину чёрного (S-Curve), гамму, цифровую насыщенность (Digital Vibrance), цветовую температуру и подсветку экрана без тяжёлых драйверных панелей и фоновой нагрузки на систему.

Работает на любых видеокартах (**Intel**, **NVIDIA**, **AMD**) и любых экранах (ноутбуки и стационарные мониторы, включая мультимониторные конфигурации).

## Возможности

- **Настройка в реальном времени** — все изменения видны мгновенно при перемещении ползунков.
- **Двойной движок цветокоррекции:**
  - **Аппаратная таблица гаммы (Hardware Gamma LUT)** через `gdi32.dll` (`SetDeviceGammaRamp`) — отвечает за нелинейную S-кривую глубины чёрного, гамму, контраст и баланс белого (температуру).
  - **Полноэкранная матрица цвета 5×5 (DWM Color Matrix)** через `Magnification.dll` — отвечает за сочность цветов (Digital Vibrance / Saturation) по весам яркости Rec.709.
- **4 готовых пресета в 1 клик** — для повседневной работы, киберспортивных шутеров (CS2 / Valorant / Fortnite) и фильмов.
- **Защита от сброса настроек (фоновый режим в трее)** — при закрытии окна программа сворачивается в системный трей, удерживая DWM-матрицу и автоматически восстанавливая гамму после сворачивания игр, UAC-запросов или выхода из сна.
- **Поддержка нескольких мониторов** — применяет калибровку ко всем активным дисплеям.
- **Автоопределение подсветки ноутбука** — регулирует аппаратную яркость встроенной матрицы через WMI (на внешних мониторах аккуратно отключается).
- **Отключение Intel DPST** — встроенная кнопка для отключения динамического снижения контраста на ноутбуках с графикой Intel.
- **Полная портативность** — один `.exe` файл весом ~68 КБ, не требует установки, библиотек или прав администратора (права нужны только для кнопки Intel DPST).

## Быстрый старт

1. Распакуйте архив и запустите **`UltraContrast.exe`** из любой удобной папки.
2. Выберите один из готовых пресетов или настройте ползунки под свой экран.
3. При необходимости поставьте галочку **«Закрепить настройки (Автозагрузка с Windows + защита от сброса в играх)»**.
4. Нажмите **«СОХРАНИТЬ И ЗАКРЕПИТЬ ПРОФИЛЬ»** и закройте окно — программа продолжит работу в трее с минимальным потреблением ресурсов.

> **Управление из трея:**
> - **Двойной клик** по иконке в трее открывает окно настроек.
> - **Правый клик** позволяет мгновенно переключить пресет, сбросить экран к заводским настройкам (1:1) или выйти из программы.

## Параметры командной строки (CLI)

Утилиту можно использовать в скриптах, ярлыках или планировщике задач:

```bat
UltraContrast.exe                         :: Открыть графический интерфейс
UltraContrast.exe --daemon                :: Запустить фоновый режим в трее с сохранённым профилем
UltraContrast.exe --apply                 :: Применить сохранённый профиль и запустить фоновую защиту
UltraContrast.exe --preset UltraContrast  :: Выбрать пресет (UltraContrast | CS2Esports | OledCinema | Default)
UltraContrast.exe --preset CS2Esports --apply  :: Мгновенно применить киберспортивный пресет
UltraContrast.exe --reset                 :: Полностью сбросить экран к заводским 1:1 и выключить автозагрузку
UltraContrast.exe --disable-dpst          :: Отключить Intel DPST в реестре (требуются права администратора)
UltraContrast.exe --help                  :: Показать справку по флагам
```

## Как это работает под капотом

1. **Монотонная степенная S-кривая (Power S-Curve):**
   В отличие от грубого линейного контраста, который «съедает» детали в тенях, используется гладкая S-образная функция с защитными границами `Win32k` — тёмные оттенки становятся заметно глубже (уходит характерная «серая дымка» IPS/TN-матриц), но детали в тенях сохраняются.
2. **DWM 5×5 Color Matrix (Digital Vibrance):**
   Через системный Windows `Magnification API` применяется матрица насыщенности по коэффициентам яркости стандарта **Rec.709** (`R: 0.2126`, `G: 0.7152`, `B: 0.0722`). Это работает на уровне композитора Windows независимо от производителя видеокарты.
3. **Хранение конфигурации:**
   Профиль сохраняется локально в:
   ```text
   %APPDATA%\UltraContrast\profile.json
   ```
   Автозагрузка (если включена) регистрируется в ветке текущего пользователя:
   ```text
   HKCU\Software\Microsoft\Windows\CurrentVersion\Run\UltraContrast
   ```

## Системные требования

- **ОС:** Windows 10 / Windows 11 (x64 и x86), также поддерживается Windows 7 SP1 / 8 / 8.1 с установленным .NET Framework 4.x (в Windows 10/11 уже встроен в систему).
- **Права администратора:** не требуются (нужны только при нажатии кнопки `Отключить Intel DPST`).
- **Зависимости:** отсутствуют.

## Частые вопросы (FAQ)

**Как полностью вернуть стандартные цвета Windows?**  
Нажмите в программе кнопку **«Заводской стандарт (Сброс 1:1)»** и закройте окно, либо выберите **«Сбросить к заводским (1:1)»** в меню иконки в трее, либо запустите `UltraContrast.exe --reset`.

**Почему ползунок подсветки матрицы неактивен?**  
Управление аппаратной подсветкой через WMI (`WmiMonitorBrightnessMethods`) поддерживается только встроенными экранами ноутбуков и моноблоков. На стационарных ПК с внешними мониторами яркость самой подсветки регулируется кнопками монитора, при этом вся цветокоррекция (контраст, S-Curve, гамма, насыщенность, температура) работает полностью.

**Зачем нужна кнопка «Отключить Intel DPST»?**  
На многих ноутбуках с интегрированной графикой Intel по умолчанию включена функция энергосбережения *Display Power Saving Technology (DPST)*, которая автоматически «приглушает» контраст на тёмных сценах и портит калибровку. Кнопка автоматически находит видеоадаптер Intel в реестре и отключает DPST (после применения рекомендуется перезагрузка).

**Windows SmartScreen показал предупреждение при первом запуске — это нормально?**  
Да, это стандартное поведение Windows для любых новых независимых `.exe` без платной цифровой подписи EV Code Signing. Нажмите *«Подробнее» → «Выполнить в любом случае»*.

## Сборка из исходников

Для сборки не требуется Visual Studio или сторонние SDK — используется встроенный в Windows компилятор `csc.exe` из состава .NET Framework 4.x:

1. Скачайте файлы репозитория (`UltraContrast.cs`, `build.bat`, `app.ico`).
2. Запустите **`build.bat`** (двойным кликом или из командной строки).
3. В той же папке появится готовый исполняемый файл `UltraContrast.exe`.

### Структура репозитория

```text
├── UltraContrast.cs   # Весь исходный код (движок LUT + DWM Matrix + UI + трей)
├── build.bat          # Скрипт сборки через встроенный csc.exe (.NET 4.x AnyCPU)
├── app.ico            # Иконка приложения
├── README.md          # Документация
└── LICENSE            # Лицензия MIT
```
